# Docker Troubleshooting

A comprehensive presentation on diagnosing, debugging, and resolving common Docker issues.

## Files

- [index.html](index.html) -- reveal.js presentation (GitHub Pages)
- [presentation.md](presentation.md) -- Markdown version

## Topics Covered

- Troubleshooting methodology
- Container lifecycle and exit codes
- Docker logs and log drivers
- docker exec for live debugging
- docker inspect deep dive
- docker stats and resource monitoring
- Debugging build failures
- Layer caching issues
- Networking problems (DNS, connectivity, port conflicts)
- Volume and permission issues
- Container restart loops
- Image pull errors and registry issues
- Disk space problems and pruning
- Performance debugging (CPU, memory, I/O)
- Docker daemon logs
- Useful debugging tools (dive, ctop, lazydocker, nsenter)
- Troubleshooting cheat sheet

## Viewing

Open `index.html` in a browser or visit the GitHub Pages URL after enabling Pages in repo settings.
